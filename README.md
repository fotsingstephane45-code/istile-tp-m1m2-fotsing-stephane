# ISTILE Annuaire

Auteur : Stéphane Fotsing

Mini-annuaire des étudiants d'ISTILE réalisé dans le cadre du Mini-TP des modules 1 et 2.
Il comprend une page web responsive, un programme JavaScript qui calcule des statistiques
à partir d'un fichier JSON, et un chargement de données depuis l'API publique dummyjson.com.

## Lancement

    npm start
